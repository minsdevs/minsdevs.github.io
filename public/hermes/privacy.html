개인정보 처리 안내

적용 대상: Codex Calendar · Hermes · 기준일: 2026년 10월 15일

이 앱은 운영자 본인의 Google 계정 두 개를 연결하는 개인 도구입니다. 아래 내용은 Mac에서 실행하는 Hermes와 같은 OAuth 앱을 사용하는 Calendar MCP 클라이언트의 Google 데이터 처리에 관한 안내입니다.

접근하는 데이터와 목적

  • 계정 식별: 연결한 계정이 의도한 본인 계정인지 확인하기 위한 계정 정보와 이메일 주소를 사용합니다.
  • Gmail: 메일 식별자, 제목·발신자 등 헤더와 본문을 읽어 분류·요약하고 과제·일정·마감 근거를 찾습니다. Gmail 읽기 권한으로 메일을 발송하거나 수정하지 않습니다.
  • Calendar: 접근 가능한 캘린더 목록과 선택한 캘린더의 이벤트를 조회하고, 요청 또는 허용된 자동화에 따라 이벤트를 관리합니다.
  • Tasks: 선택한 할 일 목록과 작업의 제목·기한·완료 상태를 읽고 관리합니다.

요청한 Google 권한 안에서 선택한 계정과 저장 대상을 사용합니다. 이 사이트에는 실제 계정 정보나 개인 콘텐츠를 게시하지 않습니다.

Google 사용자 데이터의 사용과 외부 전달은 Google API Services User Data Policy의 Limited Use 요구사항을 따르며, 사용자가 허용한 개인 업무 기능을 제공하는 범위로 제한합니다.

로컬 보관과 보호

Hermes는 조회한 메일, 일정·할 일 관련 상태, 원문 근거와 알림 상태를 Mac의 로컬 SQLite 데이터베이스에 보관합니다. OAuth 인증 정보는 별도의 로컬 파일로 관리하며 파일 권한 0600으로 접근을 제한합니다. 이는 같은 운영체제 사용자 권한이나 기기 침해까지 막는 보안 격리를 의미하지 않습니다. Calendar MCP 클라이언트의 인증 정보와 실행 환경도 운영자가 로컬에서 관리합니다.

보관 기간은 개인 업무에 필요한 기간 동안 운영자가 관리합니다. 연결 해제만으로 기존 로컬 캐시나 백업이 자동 삭제되지는 않으며, 필요 없어진 데이터·인증 파일·백업은 운영자가 별도로 삭제합니다.

외부 전달과 사용 제한

사용자가 허용한 분류·요약에 필요한 Google 데이터만 Anthropic API로 전달할 수 있습니다. Google 데이터의 기본 보관소로 GPT 클라우드를 사용하지 않습니다. 운영자는 데이터를 광고, 판매 또는 모델 학습용으로 제공하지 않습니다. 이 설명은 외부 제공자의 모든 보관·처리 행위를 보장한다는 뜻이 아니며 외부 처리는 해당 제공자의 정책에도 따릅니다.

Telegram 또는 Signal 대화 창을 선택하면 사용자의 메시지와 비서 응답·알림을 해당 메신저가 처리합니다. 비서가 답변에 포함한 개인 정보도 그 메시지의 일부가 될 수 있습니다. Google API 통신은 Google이 처리합니다.

연결 철회와 삭제

Google 계정의 서드 파티 연결 관리에서 앱의 접근을 철회할 수 있습니다. 이후 로컬 OAuth 토큰을 삭제하고 동기화 작업을 정지하면 해당 연결을 사용하지 않게 됩니다. 과거에 만든 Google 일정·할 일, 로컬 캐시·백업과 메신저 메시지는 연결 철회와 별도로 각 저장 위치에서 관리해야 합니다.

운영과 변경

운영자 본인만 사용하므로 별도 고객 계정이나 고객지원 접수 서비스를 운영하지 않습니다. 데이터 처리 범위가 달라지면 이 페이지를 갱신하고 필요한 권한을 다시 확인합니다.
