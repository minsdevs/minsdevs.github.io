개인용 Google 연동 도구

Codex Calendar · Hermes

본인의 메일, 일정, 할 일을 연결해 관리하는 개인용 도구입니다.

운영자가 자신의 Google 계정 두 개를 연결해 사용합니다. Mac에서 실행하는 Hermes 개인 비서와 기존 Calendar MCP 클라이언트가 같은 OAuth 앱의 승인 절차를 사용합니다. 일반 이용자를 모집하는 서비스가 아니며 회원가입이나 결제를 제공하지 않습니다.

Google 연결로 하는 일

  • Gmail 읽기: 허용한 계정의 메일을 조회하고 업무·학사 관련 내용과 마감 근거를 정리합니다. 이 앱의 Gmail 접근은 읽기 전용입니다.
  • Calendar 조회 및 이벤트 관리: 선택한 캘린더의 일정을 조회하고 사용자가 요청하거나 허용한 자동화 범위에서 이벤트를 관리합니다. 기존 Calendar MCP 클라이언트도 승인 범위의 일정 작업에 사용합니다.
  • Tasks 관리: 선택한 목록에 할 일을 만들고 수정하며, 사용자의 요청과 Google 완료 상태를 반영합니다.

로컬 실행과 선택적 외부 처리

개인 데이터와 인증 정보는 운영자의 Mac에서 관리합니다. 사용자가 허용한 분류·요약에는 필요한 내용을 Anthropic API로 전달할 수 있습니다. 선택한 Telegram 또는 Signal을 대화 창으로 사용할 경우 해당 메신저가 메시지를 처리합니다. 이 정적 소개 사이트는 Google 계정 로그인이나 토큰 입력을 받지 않습니다.

연결 전에 접근 데이터·보관·외부 처리·철회 방법과 자동화의 범위와 이용상 주의사항을 확인할 수 있습니다.
